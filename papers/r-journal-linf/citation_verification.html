aitchison1986book
verified		 Introduction: classical compositional analysis represents strictly positive compositions through log-ratios. Chapters 2, 5, and 7 develop the simplex and log-ratio/log-contrast representation of compositional data. source John Aitchison (1986), The Statistical Analysis of Compositional Data, Chapman and Hall. DOI 10.1007/978-94-009-4109-0.
compositionsPackage
verified		 Introduction and software comparison: compositions implements the Aitchison approach to positive compositional data, including log-ratio coordinates and statistical methods. The CRAN description says that the package provides analysis of compositional and positive data in the approach proposed by Aitchison and Pawlowsky-Glahn; the reference manual documents the compositional classes and log-ratio operations. source van den Boogaart, Tolosana-Delgado, and Bren (2026), compositions 2.0-9.
robCompositionsPackage
verified		 Introduction and software comparison: robCompositions supplies robust compositional estimation, principal components, regression, and multiple methods for zero handling. The CRAN description lists robust estimation, robust PCA and regression, missing-value imputation, rounded-zero replacement, count-zero methods, and methods for essential zeros. source Templ, Hron, and Filzmoser (2026), robCompositions 2.6.0.
zCompositionsPackage
verified		 Introduction and software comparison: zCompositions provides preprocessing methods that replace zeros, left-censored values, and missing values in compositional datasets. The CRAN title and description state this scope explicitly and link the supporting 2015 imputation article. source Palarea-Albaladejo and Martín-Fernández (2026), zCompositions 1.6.2.
MatrixPackage
verified		 Software design: Matrix provides the sparse matrix classes accepted by the linf sparse backend. The CRAN description documents a hierarchy of sparse and dense matrix classes and efficient operations backed by BLAS, LAPACK, and SuiteSparse. source Bates, Maechler, and Jagan (2026), Matrix 1.7-6.
linfPackage
verified		 Introduction and availability: linf implements L-infinity normalization, dominance assignment, hierarchical dCSTs, transfer, landmarks, and the demonstrated data workflows. The version-controlled DESCRIPTION, exported documentation, tests, and vignettes in the public repository support the software description. The development version 0.3.0 is directly supported by the public repository; the article's submission gate separately requires that version to be public on CRAN. source Pawel Gajer (2026), linf 0.3.0 development source. The package DOI 10.32614/CRAN.package.linf currently resolves to the public CRAN release; the version gate prevents article submission until CRAN publishes 0.3.0.
gajerRavel2025linf
verified		 Introduction: the separate methods paper develops L-infinity normalization, dominance regions, and the associated compositional geometry. The preprint defines the L-infinity representation, its dominance decomposition, and the associated compositional geometry. source Pawel Gajer and Jacques Ravel (2025), arXiv:2503.21543, DOI 10.48550/arXiv.2503.21543.
ravel2011vaginal
verified		 Introduction: the original vaginal CSTs were obtained by clustering 16S rRNA community profiles. The Methods describe complete-linkage hierarchical clustering of community-composition data; the Results identify five major community groups, four dominated by individual Lactobacillus species. source Ravel et al. (2011), PNAS 108(S1), 4680-4687. DOI 10.1073/pnas.1002611107.
france2020valencia
verified		 Introduction and vaginal example: VALENCIA assigns profiles to fitted CST reference centroids and provides the public training resource underlying the bundled demonstration data. The Methods define the thirteen centroid profiles and assignment by maximum similarity. The article links the public VALENCIA data repository. source data France et al. (2020), Microbiome 8:166. DOI 10.1186/s40168-020-00934-6.
